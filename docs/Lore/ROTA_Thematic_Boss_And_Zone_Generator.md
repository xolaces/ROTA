# ROTA — Thematic Boss and Zone Generator

## Purpose
This generator gives a repeatable structure for producing new boss and zone content that remains tied to the world graph.

---

## I. Boss Formula

Every boss should originate from a place that has a specific historical wound.

### Boss structure
- Name
- Place of origin
- Historical cause
- Current function
- Why the player must fight it
- What it leaves behind after defeat

### Example
- Name: The Pale Warden
- Place: a broken old-guard frontier pass
- Historical cause: a failed defense line that never stopped enforcing orders
- Current function: guardian of a route that should have died long ago
- Player need: to pass or reclaim the route
- Aftermath: relic seals and broken command gear

---

## II. Zone Formula

Each zone should contain:
- a place identity
- an origin wound
- danger pressure
- faction stakes
- a natural raid family
- a relic residue

### Zone example
- Zone: Bellwether of the Red Pass
- Place identity: mountain pass and siege line
- Origin wound: a battle that outlasted the age that fought it
- Danger pressure: the field still enforces old command logic
- Faction stake: the Iron Weir wants the pass reopened; Malachar's crews want the sigils used
- Raid family: pass-siege, gate-guardian, broken banner fights
- Relic residue: command sigils, pass-badges, old banner iron

## V. Output Standard

When generating a new boss or zone, include:

1. Name
2. Location
3. Historical wound it embodies
4. Faction interest
5. Combat style or encounter logic
6. Loot / relic residue
7. Continuity link to nearby quests or raids

That closes the loop between worldwriting and gameplay.

---

## VI. Future Use

This should be used as a repeatable template for all future content work. If a region, raid, boss, or relic cannot map into this structure, it is not yet ready to be accepted as part of the Aldenmor canon.
